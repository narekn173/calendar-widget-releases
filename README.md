# Calendar Widget — installers

A glass calendar widget for the Windows 11 desktop: Google Calendar and Outlook with two-way sync, Google Tasks,
six views, a collapsible strip at the screen edge. Russian, English and Dutch.

**Download:** [latest version](https://github.com/narekn173/calendar-widget-releases/releases/latest) → `CalendarWidget-Setup-<version>.exe`.
It installs for the current user only — no administrator rights. To update, press **⋯ → Updates → Update** in the widget,
or run a newer installer over the old one: settings, sign-ins and events stay.

Only installers are published here; the source code is private.
About the widget and its privacy policy: https://narekn173.github.io/calendar-widget/ ·
License: [PolyForm Noncommercial 1.0.0](https://polyformproject.org/licenses/noncommercial/1.0.0/) — free to use and change, not for making money.

**Windows may warn about the installer**, because it is not signed with a paid certificate:
- *Windows protected your PC* (SmartScreen) → **More info** → **Run anyway**.
- *Smart App Control blocked an app* — Windows has no per-app exception for this; the widget runs only while Smart App Control is off.
